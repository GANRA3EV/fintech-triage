# Проверка локальной модели, 17.10.2026

## Исследовательский запуск, версия 0.4.0

Полный набор с `TEST_LOCAL_HF=1`: 43 теста пройдены. Дополнительно выполнено
сравнение частотного классификатора, TF-IDF и RuBERT на общем синтетическом
наборе. Все три варианта завершились успешно. Сохранены прогнозы, метрики,
матрицы ошибок, парные интервалы Macro-F1, длительность и выборочные измерения RSS.
Проверены исключение критических прогнозов из автоматической обработки,
раздельные счётчики очистки, общие тестовые строки и запрет перезаписи.

e5 в данном прогоне не запускался. Ревизия весов закреплена по API Hugging Face
на `d128750597153bb5987e10b1c3493a34e5a4502a`.
Качество на реальных обращениях, смена временного периода и качество резюме
в исследовательском сравнении не оценивались.

Использованы реальные веса `cointegrated/rubert-tiny2`, ревизия
`e8ed3b0c8bbf4fb6984c3de043bf7d2f4e5969ae`. Проверка выполнена на CPU
в Windows с PyTorch `2.14.1+cpu` и Transformers `5.20.1`.

Специальный набор проверки Hugging Face завершился успешно: 6 тестов.
Полный набор версии 0.3.0 с реальными весами завершился успешно: 37 тестов,
включая проверку общего кэша кодировщика.
Проверены загрузка модели, нормированные векторы размерности 312, длинный
вход из 1200 повторов слова, локальное резюме и обучение классификаторов
на синтетических размеченных строках. В тестах нет вызовов Qwen API.

Результаты показывают работоспособность кода. Предметное качество, скорость
массовой обработки и расход оперативной памяти не оценивались. Для оценки
точности нужны реальные размеченные данные и отдельная тестовая выборка.
Резюме извлекает исходные предложения. Генерация пересказа и извлечение
произвольных полей в такую замену не входят.
