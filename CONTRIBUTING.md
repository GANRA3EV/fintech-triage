# Разработка

Каждая доработка сопровождается описанием задачи, изменением кода и проверкой результата. Не добавляйте реальные обращения и секреты в коммиты, задачи GitHub и журналы CI.

## Проверка перед коммитом

```powershell
.venv/Scripts/python -m pytest -q
git diff --check
```

Исправления ошибок получают версию 0.x.y с увеличением y. Новые возможности увеличивают x. Перед тегом обновляются версия в `pyproject.toml`, `triage/__init__.py` и запись в `CHANGELOG.md`. Тег указывает на проверенный коммит. Существующие опубликованные теги не перемещаются.

Сообщение коммита называет конкретную доработку. Даты отражают фактическое время работы. Внешняя публикация релиза выполняется после подключения GitHub. Локальный тег сам по себе не создаёт GitHub Release.
